# Object-Oriented Software Development

Coursework demonstrating object-oriented design and implementation (primarily in **Java**), with an emphasis on writing maintainable code.

**Tech Stack:** Java • Design Patterns • Unit Testing • Modular Code

## What this repository demonstrates
- Comfort reading/writing **OOP** code (classes, interfaces, encapsulation)
- Applying clean structure and separation of concerns
- Debugging and improving existing code

### Project Highlights for Production Support:
* **Code Maintainability:** Utilized OOP principles (Inheritance, Polymorphism) to create readable, modular codebases.
* **Debugging Logic:** Structured applications to isolate faults quickly, a critical skill for performing Root Cause Analysis on production incidents.
* **Testing:** Implemented unit tests to validate logic and prevent regression, aligning with release management best practices.

## Topics covered (typical)
- Classes/objects, inheritance, polymorphism
- Interfaces and abstraction
- Exception handling and defensive coding
- Basic design principles and refactoring

## Why it matters for Production Support
Effective root cause analysis often requires tracing behavior through an OOP codebase and identifying where failures originate.
